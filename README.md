# Digital Computer — Bhanvad

GitHub Pages ready Gujarati business website.

## Publish
1. Create a GitHub repository, e.g. `digital-computer-bhanvad`.
2. Upload this project's files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save and open the GitHub Pages URL.

## Structure
- `index.html`
- `assets/css/style.css`
- `assets/images/` (for future photos/logo)
- `.nojekyll`
